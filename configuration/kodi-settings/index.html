Kodi addon settings

These are the settings you see in Kodi, in Add-ons → Elementum → Configure. The list is generated from the addon’s settings.xml of the latest release, so it is always in sync with the addon.

  • Setting is the name shown in Kodi (English).
  • ID is the key used in settings.xml, in exported config files and in Kodi’s userdata/addon_data/plugin.video.elementum/settings.xml.
  • Default and Values show the default and the allowed values (for sliders, the range).
  • Rows in italics are hints Kodi shows inside the settings dialog.

Some settings are only visible when another one is enabled (for example, memory size only for the Memory storage).

From plugin.video.elementum v0.1.116.

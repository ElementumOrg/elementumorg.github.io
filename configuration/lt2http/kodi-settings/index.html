Kodi add-on settings

These are the settings you see in Kodi, in Add-ons → Services → LT2http → Configure.

  • Setting is the name shown in Kodi (English).
  • ID is the key in Kodi’s userdata/addon_data/service.lt2http/settings.xml, and the name of the matching lt2http option.
  • Default and Values show the default and the allowed values (for sliders, the range).
  • Rows in italics are hints Kodi shows inside the settings dialog.

From service.lt2http v0.0.17.

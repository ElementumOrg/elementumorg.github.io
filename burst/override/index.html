How to override a provider

There are a few ways to change a provider or add your own locally. All files below go into Burst’s data folder, USERDATA/addon_data/script.elementum.burst/. See where to find the USERDATA folder.

Add a custom provider with a JSON file

Put JSON files into USERDATA/addon_data/script.elementum.burst/providers/, each of them with provider definitions. See the Provider definition reference for the format.

Note

These providers are always enabled: Kodi add-on settings are static, so Burst can’t add switches for them.

Override a provider with a Python script

Create an overrides.py file in USERDATA/addon_data/script.elementum.burst/, like this:

overrides = {
    'torlock': {
        'name': 'MyTorLock'
    },
    'freshon.tv': {
        'tv_keywords': '{title} s{season:2}e{episode:2}'
    }
}

Override a provider with a JSON file

The simplest way is a single overrides.json file in USERDATA/addon_data/script.elementum.burst/, like this:

{
    "rutor": {
        "name": "Bla-bla",
        "color": "red"
    },
    "yts": {
        "parser": {
            "name": "item('a', order=2)"
        }
    }
}

Open the current definitions, copy the provider you need into overrides.json and change it. Or keep only the keys you change, so it’s clear what you override.

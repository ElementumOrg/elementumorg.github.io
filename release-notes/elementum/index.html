Elementum

0.1.117

  • Added “Random” to Movies and TV Shows: a shuffled set of popular TMDB titles, different on every visit, to discover something you have not seen yet. (#802)
  • Added “Popular people” to Movies and TV Shows: TMDB popular actors, open one to see their movies or shows (shows they have most episodes in come first, talk shows and other guest appearances are skipped). (#802)
  • “My Progress” in TV Shows (shows you are watching, with the next episode to watch) now works with Simkl and MDBList too, and its settings (sorting, colors, hiding unaired episodes) are shown for every tracking service. When a list needs a paid account of the tracking service, you get a notification saying so instead of an empty list.
  • Playback progress from your tracking service is now shown in Elementum lists and offered for resume also for movies and episodes that are not in Kodi library.
  • Added “Remove from Elementum library, when item is deleted from Kodi library” setting: movies and shows you remove in Kodi are removed from Elementum library too, so they are not added back on the next sync. Refreshing an item in Kodi does not count as removal.
  • Added “Select userlists to sync” setting to choose which of your tracking service lists are synced into the library (all lists, if none selected).
  • Added “Rename moved files to Kodi naming” setting: completed downloads moved to the library folder are renamed like “Title (Year)” for movies and “Show (Year) S01E02” for episodes, with subtitles and .nfo files renamed to match. Files that cannot be recognized, or whose new name is taken, keep their original name.
  • Torrent status overlay is now shown also while the player info or OSD is open, not only on pause. (#326)
  • Resolution preference settings now show where 4K is placed in the order. (#820)
  • Subtitle addons now get proper details when playing from torrent search: a movie, or an episode with show name, season and episode read from the file name, so they can find subtitles.
  • Kodi library is rescanned once at the end of tracking service sync, instead of after every synced list.
  • Removed torrents keep their resume data while downloaded files stay on disk, so adding the same torrent again does not re-check all of its data. Changed file dates no longer cause a full re-check either.
  • Fixed playback being stopped and the torrent removed while an external player is still playing it. (#1053)
  • Fixed “Download” from the context menu showing a “Playback failed” dialog and not starting the download. (#960)
  • Fixed library entries of movies, shows and episodes with the same TMDB ID overwriting each other, which could mark the wrong item as deleted. Existing library is fixed on start.
  • Fixed .strm files not being removed when the same movie or episode is downloaded into the library folder.
  • Fixed completed downloads being lost when moving them failed: moving is retried, and the download folder is no longer cleaned up while it still holds files that were not moved.
  • Fixed Elementum restarting when exiting Kodi on Android, which delayed Kodi exit. (#1155)
  • Fixed Elementum lists sometimes not opening right after closing settings. (#1085)
  • Fixed dates of list items not being recognized by Kodi. (#1042)
  • Fixed saving the view mode picking a wrong (hidden) view in some skins.
  • Fixed “Yes” not being preselected in auto-confirm dialogs on Kodi older than 20.
  • Fixed the Elementum binary being downloaded again on every Kodi start for add-on builds that download it from GitHub, because the wrong (oldest) version was recorded after download.
  • Web UI: share ratio of torrents is shown up to 1000 at most.

0.1.116 - 2026-11-01

  • Added Simkl and MDBList as tracking services besides Trakt. Choose one in the new “Tracking” settings and authorize it (MDBList also accepts a personal API key): watchlist, watched history, playback progress, scrobbling and lists sync with it like with Trakt (collection is available on Trakt and MDBList only, Simkl lists need a Simkl PRO or VIP account).
  • “Tracking” settings show only the options the selected service supports, and settings that work with any service no longer mention Trakt.
  • Added “Storage statistics” action in Advanced settings to see total, used and free space of the download drive, and how much of it is taken by Elementum downloads and by leftover files.
  • Menus got their own icons for every entry (status, history, calendars, lists, watchlist, library and others) instead of reusing the same icon for different things.
  • Episodes in a season are labeled like in Kodi’s own library (“01. Title”); the list of all seasons keeps the S01E01 labels.
  • “Automatically start downloading next episode” now works for every playback, including torrents played from search, history or a link, not only for TV shows.
  • When you decline replaying the previously chosen torrent, it is also removed from cached search results, so auto-play does not pick the same (often dead) torrent again.
  • Faster loading of the torrents list, especially with many torrents.
  • Fixed library being treated as read-only (no library files written) on Kodi without video sources, e.g. Android with content set directly on detected drives.
  • Fixed playing the next episode through Up Next from torrents history sometimes failing, because the torrent file was deleted when the previous playback ended.

0.1.115 - 2026-11-01

  • Added native support for macOS on Apple Silicon (darwin_arm64).
  • Web UI: added translations (follows Kodi language), selection of Kodi to play on when several Kodi instances are connected, improved search with provider icons and download/play actions.
  • Added automatic conversion of Windows paths to WSL paths when Elementum runs under WSL with Windows Kodi (download, library, torrents and other paths).
  • Added “Advanced search” in Movies and TV Shows to search TMDB by title, year or year range, genres, countries, languages and actors (movies only), with sorting by popularity, rating, votes, release date or name.
  • Added “Clean up leftover files” action in Advanced settings to browse, play and delete files in download folder that do not belong to any torrent.
  • Added “Default view for all lists” setting to use one view for all Elementum lists. View mode is no longer applied to widgets and other containers. (Thanks to @60secondsassassin)
  • Added “Local host” setting to choose the address the add-on listens on for connections from Elementum daemon.
  • Added episode guide to TV show NFO files, so Kodi can match library shows more reliably.
  • Buffering dialog is skipped when the chosen file is already fully downloaded.
  • Free space is checked before downloading additional files of a torrent, so playback does not break by running out of space.
  • Icons and thumbnails are now shown correctly on remote Kodi clients in client-server mode.
  • Library scans and cleanups now run on the local Kodi, which fixes adding to library with shared (MySQL) library on several Kodi devices.
  • Internal proxy now supports HTTP/2, imitates the browser from the request’s User-Agent so sites are less likely to block it, and is turned on or off without restarting.
  • Added “Use built-in proxy for Elementum requests” setting to choose whether Elementum’s own requests go through the internal proxy.
  • Added “Use OpenNIC DNS Servers for regular domains” setting to resolve all domains with OpenNIC, not only OpenNIC domains.
  • Removed deprecated list item calls on Kodi 20+, which reduces warnings in kodi.log.
  • Faster list loading on Kodi 20+, and fixed lists and playback failing when an actor has no name. (Thanks to @vasilky3)
  • Fixed Elementum killing an unrelated process (even Kodi itself) on startup because of a stale lockfile.
  • Fixed Trakt authorization to use new auth.trakt.tv endpoint.
  • Fixed OpenNameServer DNS-over-HTTPS server and skipping of broken DNS-over-HTTPS providers.
  • Fixed NAT-PMP port mapping issues.
  • Fixed duplicate Kodi hosts entries for IPv4/IPv6 addresses.
  • Fixed possible crashes when torrent is removed while being used.
  • Fixed tracking of playback when Kodi moves to the next item in a playlist, and pausing of the playing Elementum video when another one is started.
  • Fixed a cancelled progress dialog staying on screen forever when Elementum daemon crashed or stopped responding.
  • Fixed ignoring all subsequent settings changes after a token (e.g. Trakt) was refreshed.
  • Fixed Cancel button in buffering dialog on Kodi 22. (Thanks to @sjq42)
  • Fixed missing error tracebacks in kodi.log. (Thanks to @sjq42)
  • Added IMDb ID, season and episode parameters to /subtitles endpoint, and upnext_off parameter to disable UpNext notifications, for external addons. (Thanks to @sk8ordi3)
  • Added skip_file_dialog play parameter to fail instead of showing file selection, and resolution_token play parameter to report failed or cancelled playback, for external addons. (Thanks to @Therand90)
  • Added doresume=never play parameter to skip the resume dialog, for external addons.
  • Completed translations for 20 languages, fixed Spanish “earliest release date” strings. (Thanks to @andresiko)

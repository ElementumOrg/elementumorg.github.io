Burst

v0.0.101 - 2026-11-01

  • Version 0.0.101
  • Expired cookies are no longer used for searches and torrent downloads, a warning asks to re-sync cookies in the browser.
  • Subpage requests stop shortly before the search timeout, so providers still report their results in time.
  • Fixed parsing of numbers like “5.0” or “1.2K”, that were glued into one number.
  • Fixed peers count for RuTracker.
  • Translations moved to standard Kodi language folders.

v0.0.100 - 2026-10-28

  • Version 0.0.100
  • Show provider login and cookie sync errors during search and in the final notification.
  • Cookie sync: ignore expired cookies and fall back to login instead of using them.
  • Cookie sync: find the gist file when the account has many gists, and no longer fail when the file cannot be downloaded.
  • Cookie sync: match cookies to the correct tracker domains and use the synced user-agent for torrent downloads.
  • Fixed missing results: torrents without an info hash were merged into a single result.
  • Fixed searches hanging when a tracker is slow or a provider crashes.
  • Fixed failed logins being treated as successful.
  • Fixed login on trackers using Windows-1251 or other non-UTF-8 charsets, and with special characters in credentials.
  • Fixed parsing of seeds and peers with thousand separators.
  • Fixed proxy handling with Antizapret and Elementum’s hosts resolve mode.
  • Fixed lowercase custom headers not overriding default headers.
  • Fixed duplicate custom providers and API providers returning no results when a single row is broken.
  • Improved search speed and reduced rate limiting by making fewer duplicate requests and limiting parallel subpage requests.
  • OpenNIC DNS servers are now used only when custom DNS is enabled.
  • Updated French trackers (Cpasbien, Torrent9) as of 18.07.2026 (#500). Thanks to @antonsoroko.
  • Dropped support for Kodi 18, Kodi 19 or newer is required.

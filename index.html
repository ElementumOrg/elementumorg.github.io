Stream torrents in Kodi. Documentation of the ElementumOrg projects: the Elementum add-on and the LT2http streaming engine.

Elementum

Elementum finds movies and TV shows with the Burst search add-on, starts playing while the torrent downloads, keeps a virtual library in Kodi and syncs your watch history with Trakt, Simkl or MDBList. Latest releases: Elementum v0.1.118 · Burst v0.0.102 · Context v0.0.17.

Quick start

  1. In Kodi, open Settings → Services → Control and enable both Application control options (remote control).
  2. Download the ElementumOrg repository zip from Downloads and install it with Add-ons → Install from zip file.
  3. Open Add-ons → Install from repository → ElementumOrg repository and install Elementum, and Elementum Burst for searching.

More details and screenshots are in Installation.
